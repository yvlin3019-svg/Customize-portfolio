# 客製化商品計算系統（カスタマイズ実績）

中文 | [日本語](README.ja.md) | [English](README.en.md)

店舗客製化商品的**日結計算＋月度統計**系統。每天輸入完後可以直接複製當日合計、貼到 LINE 報告；月底自動產出每個人的件數、デリート／マルチ比例、品相分布，並用「圓點＝貼紙」的方式呈現，取代原本的手算、手動製表和貼貼紙。

## 背景：要解決的問題

店裡的客製化服務分成 **マルチ（正價）** 和 **デリート（折扣）** 兩種，マルチ又細分為 Tabby、シューズ、その他 等品相。原本的作業流程是：

- 每天晚上**手算**當天的件數、unit 數和稅抜金額，整理成固定格式的文字發到 LINE
- 月底**手動製作兩張表**：每人每週的マルチ／デリート件數，以及每人每週的マルチ品相
- 每個人要在表上**貼上對應顏色的貼紙**，代表各自完成的品相

這套流程有幾個問題：

1. **費時又容易出錯**：每天手算，稅込換稅抜、unit 加總都可能算錯。
2. **貼紙容易忘記貼**：忘記貼會造成月底結算的誤差，而且事後很難回頭確認。
3. **進度看不到**：月度目標（例如 160 件）要到月底才知道差多少，無法在月中調整節奏。
4. **每個月都要重新拉表格**：公司採用特殊的會計年度（例如 FY27 從 6/28 開始，P4 為 9/27〜10/31），每個月度的天數和週的劃分都不一樣。

## 系統架構

系統分成三個部分，**依照店裡實際的分工設計**：

| 部分 | 誰在用 | 做什麼 |
|---|---|---|
| **日次入力** | 每晚負責結帳的人 | 快速輸入當天的每一筆，自動算出合計，一鍵複製到 LINE |
| **カレンダー** | 每位同仁 | 點開某一天，替自己做的商品補上擔當和品相 |
| **月度集計** | 店長／全員 | 看目標進度、每人成績、週表，並輸出報表 |

另外還有**設定**頁，可以管理員工名單、月度與目標，以及品相和貼紙顏色。

這樣的分工是整個設計的核心：**「輸入」和「歸屬」分開**。結帳的人只需要專心把數字輸入正確，不必知道每一件是誰做的；每個人事後再自行補上擔當和品相。日次入力因此能保持最簡單的樣子，不會因為功能增加而變得難用。

## 功能總覽

### 頂部進度卡

每一頁的最上方都會顯示**目前月度、期間、目標件數、截至今天的完成件數、達成率**，並附上進度條，一打開就知道目前的進度。

### 日次入力

<img src="screenshots/daily-desktop.png" width="720" alt="日次入力（電腦版）">

- 選擇デリート／マルチ，輸入件數、パーツ數、**稅込金額**，系統會**自動換算成稅抜**（支援 10%／8%）。
- 當日合計會自動整理成 LINE 報告用的固定格式，**一鍵複製**即可貼上：
  ```
  6件15unit ¥232,000（マルチ4件10unit ¥193,000）M2件
  ```
- モノグラミング（M）另外以每日件數記錄。
- 下方的「当日の明細」讓人在送出報告前做最後確認，刪錯了也能按「元に戻す」復原。

### カレンダー

- 以月度為單位顯示日曆，**每一格只顯示日期和當天件數**，保持畫面簡潔，手機上一個畫面就能看完整個月度。
- 當天如果有明細**還沒指定擔當，或マルチ還沒選品相，格子右上角會出現紅點**提醒。
- 點開某一天可以編輯每一筆：
  - 指定擔當、選擇品相（按鈕顏色即貼紙顏色）
  - 未設定的明細會**自動排在最上面**，打開就能優先處理
  - 收在「修正」裡的進階操作：切換種類、標記員工私物、修改件數與金額，以及**把一筆多件拆成每筆 1 件**（對應一筆裡有不同擔當或品相的情況）

### 月度集計

<img src="screenshots/monthly-desktop.png" width="720" alt="月度集計（電腦版）">

- **三種進度指標**：
  - **達成率**：完成件數 ÷ 目標
  - **今日までの目標**：若每天平均進行，到今天應該完成幾件（進度條上的紅線），可以直接看出目前是超前還是落後
  - **必要ペース**：剩下的天數裡，每天需要完成幾件才能達標
- **累計推移圖**：實線是累計實績，虛線是目標線，兩者的差距就是進度落差。
- **スタッフ別**：每個人的マルチ／デリート件數以堆疊橫條呈現。
- **表1（マルチ／デリート）與表2（マルチ品相）**：重現店裡原本的兩張紙本表，按週（日〜土）統計。**一個圓點代表一件，也就是一張貼紙**，顏色直接對應貼紙顏色，比數字更容易看出累積的程度。
- 還沒指定擔當的件數會獨立列成「担当未設定」，不會漏算，頁面上方也會提醒。

### 輸出

<img src="screenshots/report.png" width="720" alt="印刷用ファイル">

| 按鈕 | 內容 |
|---|---|
| **印刷用ファイル** | A4 橫向的月度報表：每人的金額、件數、デリート／マルチ件數與比率、各品相件數與比率 |
| **集計表 CSV** | 和報表相同內容的 CSV，可以直接用 Excel 開啟 |
| **明細 CSV** | 每一筆的原始紀錄，方便對帳或備份 |

螢幕上用圓點呈現，**輸出時則改成方便統計的數字**。CSV 採用 Excel 能正確讀取日文的編碼，打開不會出現亂碼。

### 設定

<img src="screenshots/settings.png" width="240" alt="設定">

- **員工**：以標籤排列，新增後可**直接拖曳調整順序**。點一下名字會出現「非表示」和「削除」。
- **月度與目標**：設定每個月度的名稱、期間和目標件數。**週會自動以星期日到星期六劃分**，4 週或 5 週的月度都能正確處理；「＋次の月度」會接在上一個月度後面自動建立。
- **品相與貼紙顏色**：可以自由新增、改色、排序、刪除。

## 設計亮點

- **非破壞性的資料管理**：員工離職時用「非表示」，他就不會再出現在選單裡，但**過去的紀錄和報表都會保留他的名字**。品相也是一樣，就算刪除，也不會讓舊資料消失或顯示錯誤，而是回到「未設定」，可以重新指定。
- **防止漏設定**：紅點、未設定置頂、月度頁的提醒，三層機制確保每一件都有歸屬，取代「忘記貼貼紙」的風險。
- **防止誤操作**：刪除後可以復原；刪除月度這類影響範圍大的操作需要按兩次確認。
- **手機優先**：所有頁面都以手機的使用情境調整過：每筆明細維持一行、分頁不需要左右滑動、日曆一個畫面放得下、輸入區不需要來回捲動。
- **多人即時同步**：資料存放在共享資料庫，一個人輸入後，其他人的畫面會即時更新；沒有編輯權限的人會自動切換成唯讀模式。
- **深色模式**：配合手機的系統設定自動切換。
- **鍵盤操作**：在電腦上也可以用方向鍵調整員工和品相的順序。

## 技術重點

- **單一 HTML 檔案**，以原生 HTML／CSS／JavaScript 撰寫，沒有使用任何框架或建置工具。
- 累計推移圖、圓點週表、進度條全部**自行繪製**（SVG 與 CSS），不依賴圖表函式庫。
- 以 CSS 變數管理配色，同時支援淺色與深色主題。
- 資料儲存使用 **Claude Artifacts 提供的共享資料庫**，下載檔案使用它的下載功能。

| 檔案 | 說明 |
|---|---|
| `customize-system.html` | 完整系統（日次入力＋カレンダー＋月度集計＋設定）。需要在 Claude Artifacts 上執行，才能使用共享資料庫。 |
| `daily-calculator.html` | 只有日結計算的獨立版本。資料存在各自的瀏覽器裡，**可以放在任何網頁空間，不需要帳號**。目前已在店內實際使用。 |

## 我的角色與開發方式

這個系統是我和 AI（Claude）協作完成的。我負責的部分是：

1. **發現問題**：從每天的實際作業中，找出手算、製表、貼貼紙這幾個環節的痛點。
2. **整理規則**：把店裡的客製化規則（マルチ／デリート、品相、會計年度的月度與週、LINE 報告格式、稅込稅抜）整理成清楚的文字需求，交給 AI 實作。
3. **反覆調整**：實際在手機上操作，逐項提出修改，例如文字大小與比例、哪些資訊該留在畫面上、哪些該收起來、一行放多少內容，讓畫面維持簡潔。
4. **預測問題**：請 AI 列出實際使用時可能發生的問題，再判斷哪些需要處理。例如「員工離職會不會讓舊紀錄消失」催生了非表示功能，「一筆裡有兩個人做的商品」則催生了分割功能。

## 限制與未來改進

**目前的狀態**：日結計算的部分（`daily-calculator.html`）已經投入店內使用。月度集計等完整系統，因為資料庫建立在個人的 Claude 帳號上，同仁需要各自有帳號並被邀請才能使用，所以還沒有進入全店實測的階段；個人測試的結果是可行的。

**未來可以改進的方向**：

- **把資料庫換成店裡或公司可以持有的服務**（例如 Google 試算表），讓完整系統能放在任何網頁空間，同仁不需要額外的帳號。
- **記錄每位同仁的モノグラミング件數**，目前只記錄全店每天的合計。
- **保留修改紀錄**，出現數字爭議時可以追溯是誰、在什麼時候改了哪一筆。
- **支援退貨和取消**，目前只能直接刪除該筆紀錄。
- **批次指定擔當**：當天的商品都是同一個人做的時候，可以一次把所有未設定的明細指定給他，不必一筆一筆選。
